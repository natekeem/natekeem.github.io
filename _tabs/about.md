# About

## 이 블로그는 무엇인가

`나태킴의 커밋로그`는 Project AI Autoblog를 만들며 남기는 1인 개발자의 솔직한 엔지니어링 기록이다.

처음에는 AI로 수익형 블로그를 전자동으로 찍어내는 마법 같은 시스템을 꿈꿨다. 하지만 실제로 코드를 짜고 운영해 보니, 자동화보다 먼저 필요한 것은 글의 엄격한 품질 기준, 1차 출처 기반의 팩트체크, 그리고 사람이 직접 검토하는 수동 검수 관문(Human Gate)이었다.

그래서 이 블로그에는 그럴듯하게 포장된 성공담 대신, 실패와 막힘, 아키텍처 결정과 실제 트러블슈팅 과정을 있는 그대로 기록한다.

## 현재 운영 중인 프로젝트

중앙 HQ(`ai-autoblog`)를 중심으로 Git Mode 160000 서브모듈 연합 구조를 통해 3개의 독립 사이트를 운영하고 있다.

1. **나태킴의 커밋로그 (Dev Blog)**
   - Ruby 3.3 및 Jekyll Chirpy 기반 개발 로그 (24편 발행).
   - AI 에이전트 오케스트레이션, 인프라 삽질기, 오픈소스 주간 트렌딩 분석을 기록한다.

2. **The Smart Suburbanite**
   - AstroPaper 기반 북미 단독주택 전문 실전 가이드 (`smartsuburbanite.com`, 22편 발행).
   - 대용량 배터리 백업, 스마트 부하 차단, 전기·안전 규격(NEC, UL) 중심의 고밀도 테크니컬 콘텐츠를 다룬다.

3. **The Noise Filter**
   - AstroPaper 기반 글로벌 테크 & 반도체 시그널 분석 매거진 (11편 발행).
   - 마케팅 노이즈를 걷어내고 하드웨어 물리 한계, 패키징 수율, 반도체 공급망의 기술적 진실을 분석한다.

## AI를 어떻게 사용하는가

이 블로그의 글과 파이프라인은 ChatGPT, Claude Code, Cursor 같은 AI 도구의 도움을 받는다.

다만 원칙은 확고하다.

```text
AI는 초안 작성을 돕는다.
사람은 방향을 결정하고 최종 검증한다.
자동화는 완전히 검증된 반복 작업에만 점진적으로 적용한다.
```

## 핵심 운영 원칙

- **수동 먼저, 자동화는 나중에**: 손으로 완벽히 통제할 수 없는 것은 자동화하지 않는다.
- **품질이 수량보다 우선**: 검색엔진을 도배하는 얇은 글 수십 편보다, 1차 출처와 도면이 있는 깊이 있는 한 편을 쓴다.
- **신뢰와 독창성**: 허위 1인칭 경험담, 가짜 전문성, 수익 과장을 엄격히 금지한다.
- **사람 검수 관문(Human Gate)**: AI 생성 콘텐츠는 인간의 대조 검증 없이 외부에 발행하지 않는다.
- **아키텍처 무결성**: 3개 사이트의 기술 스택을 침범하지 않으며, 독립 빌드와 독립 배포를 유지한다.
